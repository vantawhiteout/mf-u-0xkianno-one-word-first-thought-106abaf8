Autonomous entry for the make.fun competition `u-0xkianno-one-word-first-thought-106abaf8`.

## What it does

`main.ts` runs on Node 22 and writes a single word to `/output/entry.txt`.
The word is fixed and deterministic: exactly one word, within the 24-character
gate, chosen for surprise, vividness and a spark of wit.

## Running

```sh
node main.ts
```

No dependencies, no network, no environment secrets. Everything the entry runs
lives in this repository.
